# TRD-TMS-Analysis
**QualityChecks_1.R** This script performs a comprehensive quality control (QC) pipeline for DNA methylation array data (specifically .idat files from Illumina arrays). It installs and loads necessary R packages, reads phenotype and methylation data, evaluates sample quality using control metrics and genotype-based outlier detection, flags failed or duplicate samples, and outputs a QC-annotated phenotype file for downstream analysis.

**Preprocessing_Normalization_2.R** This script performs pre-processing and normalization of Illumina DNA methylation array data. It applies background correction and dye bias adjustment using preprocessNoob, flags and removes sex mismatches, filters low-quality and cross-reactive probes, and uses ComBat to correct for batch effects while preserving biological variables like age, sex, and treatment response. The final output is a cleaned, normalized beta value matrix ready for downstream epigenome-wide association studies (EWAS).

**CellEstimation_forEPIC_3.R** This script estimates blood cell type proportions from DNA methylation data using the EpiDISH package with the RPC method and a predefined reference matrix. It merges the estimated cell fractions with the phenotype file to account for cellular heterogeneity in downstream analyses. The output is a phenotype file annotated with cell type proportions.

**Ancestry_PCs_3.1.R** This script estimates ancestry-related principal components (PCs) from DNA methylation data using a location-based approach described by Barfield et al. (2014). It selects ancestry-informative CpG sites overlapping common SNPs, imputes missing values, and computes PCs to account for population stratification in downstream analyses.

**Smoking_Scores_3.2.R** This script calculates DNA methylation-based smoking scores using a weighted sum of methylation M-values at smoking-associated CpG sites. It adjusts for extreme beta values, converts them to M-values, applies published coefficients, and merges the resulting scores with the phenotype data. The final output is an updated phenotype file including individual smoking scores for use as covariates in downstream analyses.

**Genomic_inflation_for_combat_4.R** This script assesses genomic inflation in DNA methylation association results after ComBat batch correction. It performs an epigenome-wide association study (EWAS) using a modified cpg.assoc function, adjusting for biological covariates and estimated cell type proportions. The results include effect estimates, significance values, and test statistics for evaluating inflation, which are saved for downstream interpretation and quality assessment.

**QQPlot_genomic_inflation_factor_4.1.R** This script evaluates genomic inflation in DNA methylation EWAS results using QQ plots and the BACON method. It visualizes unadjusted and BACON-adjusted test statistic distributions to assess and correct for systematic bias or inflation in association tests. The workflow supports quality assurance before interpreting epigenome-wide results.

**Ranking_probes_and_DMR_analysis_5.R** This script prepares covariate-adjusted differential methylation statistics as input for mCSEA, a pathway enrichment tool for DNA methylation data. Because mCSEA does not natively account for covariates, the script fits linear or logistic regression models for each CpG site to assess the association between baseline methylation and clinical outcomes (e.g., binary treatment response, continuous PHQ-9 change, or remission), adjusting for relevant covariates such as age, sex, antidepressant use, cell composition, baseline symptom severity, and smoking score.
Top variable CpGs (5%) are used for modeling, and the resulting test statistics (e.g., z-values or t-values) are used to rank probes for mCSEA input. The analysis is repeated for different outcomes, and significant differentially methylated regions (DMRs) are extracted based on adjusted p-values. 

**Enrichment_Analysis_6.R** This script performs functional enrichment analysis of differentially methylated regions (DMRs) using the missMethyl package. For each clinical outcome—binary treatment response, continuous symptom change, and remission—it extracts CpGs from significant DMRs and tests for overrepresentation of Gene Ontology (GO) terms and KEGG pathways, using the top 5% most variable CpGs as the background to avoid probe bias.

**Targeted_Analysis_BDNF_7.R** This script conducts targeted differential methylation analysis of CpG sites annotated to the BDNF promoter region using ComBat-adjusted EPIC array data. Linear models are fitted with limma to test associations between BDNF methylation and three clinical outcomes: binary treatment response, continuous symptom change, and remission, adjusting for covariates including age, sex, antidepressant use, baseline symptoms, cell-type composition, and smoking score. Results are exported as CSV files with FDR-adjusted p-values for each outcome.
